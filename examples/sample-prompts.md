# Sample Prompts

## 从模糊想法开始

```text
使用 $pm-product-office-hours。我有一个产品想法：想做一个给中小企业老板用的 AI 管理助手。请你像严厉面试官一样追问我，直到能输出完整产品定义包。
```

## 从硬件 + App 新产品开始

```text
使用 $pm-product-office-hours。我想做一个儿童家庭训练硬件 + App 产品，但现在产品边界还很模糊。请先问我问题，帮我定义目标用户、真实痛点、MVP、PRD、验证计划和路线图。
```

## 使用行业模板

```text
使用 $pm-product-office-hours，并按硬件 + 教育产品模板追问我。请特别检查 BOM、结构风险、儿童体验、家长价值、训练反馈和非医疗化表达。
```

## 一小时 PRD 评审

```text
使用 $pm-product-office-hours 的一小时 PRD 评审模式。我会贴一份 PRD，请你先不要重写，先指出漏洞、缺失决策、MVP 是否过大、指标是否缺失，然后给出修正版结构。
```

## 投资人视角质询

```text
使用 $pm-product-office-hours 的投资人质询模式。请像投资人一样挑战我的市场、护城河、商业模式、团队优势和 90 天验证计划，并输出强版本回答。
```

## 输出为多种格式

```text
使用 $pm-product-office-hours。请先输出完整 Markdown 产品定义包，然后附上 DOCX-ready 结构、PPT 10 页大纲和飞书文档块结构。
```

## 上线后增长诊断

```text
使用 $pm-product-office-hours。我们的 MVP 已经上线，有 200 个注册用户但留存一般。请先追问关键数据，再输出增长诊断、指标体系、实验路线图和下一版 PRD。
```

## 快速生成，但标注假设

```text
使用 $pm-product-office-hours。我赶时间，请最多问我 5 个关键问题，然后基于已知信息输出产品定义包，并把所有假设、未知和自检分数单独列出来。
```
