# Sample Prompts

## 从模糊想法开始

```text
使用 $pm-product-office-hours。我有一个产品想法：想做一个给中小企业老板用的 AI 管理助手。请你像严厉面试官一样追问我，直到能输出完整产品定义包。
```

## 从硬件/软件新产品开始

```text
使用 $pm-product-office-hours。我想做一个儿童家庭训练硬件 + App 产品，但现在产品边界还很模糊。请先问我问题，帮我定义目标用户、真实痛点、MVP、PRD、验证计划和路线图。
```

## 从已有原型开始

```text
使用 $pm-product-office-hours。我已经有一个可点击原型，但不确定首版该做哪些功能。请严厉地帮我审一遍产品定义，输出 MVP 范围、P0/P1/P2、验收标准和验证计划。
```

## 从上线后增长开始

```text
使用 $pm-product-office-hours。我们的 MVP 已经上线，有 200 个注册用户但留存一般。请先追问关键数据，再帮我输出增长诊断、指标体系、实验路线图和下一版 PRD。
```

## 快速生成，但标注假设

```text
使用 $pm-product-office-hours。我赶时间，请最多问我 5 个关键问题，然后基于已知信息输出产品定义包，并把所有假设和未知单独列出来。
```
