## Why these are anonymized

The goal is to make the skill easy to understand without leaking a founder’s private strategy, user research, BOM, metrics, or fundraising narrative.

When contributing your own examples:

- Remove company names, customer names, and private metrics.
- Mark assumptions clearly.
- Avoid medical/legal/financial claims unless the example is explicitly framed as non-advice.
- Keep the example useful enough that a new user can understand the workflow in 3-5 minutes.
